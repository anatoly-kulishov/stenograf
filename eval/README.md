# Eval: реальные созвоны (Sprint 2)

Положи сюда 3-5 встреч. Без эталонов метрики не калибруются.

## Структура

```
eval/meetings/<id>/
  audio.wav          # одна дорожка
  # или:
  mic.wav            # «Я»
  system.wav         # собеседники
  ref.json           # эталон (обязателен)
  meta.json          # опционально: title, notes
```

`ref.json`:

```json
[
  {"start": 0.0, "end": 6.5, "speaker": "1", "text": "Добрый день. Нужен КТРУ."},
  {"start": 6.5, "speaker": "2", "text": "Понял, сделаем в Excel."}
]
```

- `speaker` - любая стабильная метка (`1`/`2`, `me`/`client`, …)
- `end` желателен для метрики пропусков; если нет - берётся окно ~4 с

Аудио и `hyp.json` / `metrics.json` (результаты прогона) в git не коммитим.

## Прогон

Из корня репо:

```bash
pnpm eval
# или одна встреча:
pnpm cli -- --eval eval/meetings/demo-synth
```

Словарь терминов: `core/data/hotwords.txt`. Отключить: `--no-hotwords`.

## Что смотрим

| Метрика | Смысл |
|---|---|
| WER | ошибки распознавания vs эталон |
| спикеры hyp/ref | диаризация не раздулась и не схлопнулась |
| пропуски | реплики эталона без пересечения по времени и общим словам |
